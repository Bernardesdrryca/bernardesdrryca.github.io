O que é

Ferramenta de uso interno, que roda no computador do dono dos canais e publica e organiza vídeos nos canais do YouTube dele (Yeshua Índio e Tumble Tunes) pela API oficial do YouTube. Não tem outros usuários.

Dados acessados

  • Vídeos, playlists e visibilidade dos canais autorizados pelo dono.
  • Nome do canal, para confirmar a conta autorizada.

Não lê comentários, mensagens, dados de inscritos, dados financeiros nem informação de terceiros.

Uso e guarda

  • Usados só para enviar vídeos, definir visibilidade e incluir vídeos em playlists do próprio canal.
  • A chave de autorização fica apenas no computador do dono, fora de qualquer repositório.
  • Nada é vendido, compartilhado ou usado para publicidade.

Como revogar

Conta Google › Segurança › Apps de terceiros com acesso › remover "AMRIF Publicador". Apagar o arquivo token.json no computador também encerra o acesso.

Políticas do Google

O uso segue a Política de Dados do Usuário dos Serviços de API do Google, os Termos de Serviço do YouTube e a Política de Privacidade do Google. Os dados do YouTube são acessados pelos Serviços de API do YouTube.

English. Private single-owner tool that uploads videos, sets visibility and manages playlists on the owner's own YouTube channels via the YouTube Data API. No third-party data; token stays on the owner's computer; nothing shared. Revoke anytime in Google Account › Security › Third-party apps.
