AMRIF Publicador

Ferramenta interna · responsável: Marco Antônio Fontes Bernardes · marcoafbernardes@gmail.com

O AMRIF Publicador é a ferramenta própria da AMRIF que publica e organiza os vídeos dos canais do YouTube da família (Yeshua Índio e Tumble Tunes) pela API oficial do YouTube. Roda só no computador do dono dos canais e não é oferecida ao público.

Esta ferramenta usa os Serviços de API do YouTube (YouTube API Services). Ao usá-la, o dono dos canais concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

English. AMRIF Publicador is a private, single-owner tool that uploads videos and manages visibility and playlists on the owner's own YouTube channels. It uses YouTube API Services; by using it you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.
